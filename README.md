# Alex Mikeylov — UI/UX Portfolio

A responsive bilingual (EN/RU) portfolio website. English is the default language.

## Files
- `index.html` — page content and links
- `styles.css` — layout and visual styles
- `script.js` — language switcher
- `assets/` — all images used by the site

## Publish with GitHub Pages
1. Upload the **contents** of this folder to the root of your `resume-site` repository.
2. Keep the `assets` folder and its filenames unchanged. The portfolio uses `assets/profile-color.jpeg`, `assets/profile-bw.png`, `assets/nomo-case-study.png`, `assets/mono-project.jpg`, `assets/arven-project.jpg`, `assets/coinly-project.jpg`, `assets/pink-bear-project.jpg`, `assets/crystal-icon.png`, `assets/crystal-rush.png`, `assets/wordout-icon.png`, and `assets/wordout-screens.png`.
3. Commit the changes.
4. In Settings → Pages, choose **Deploy from a branch**, select `main` and `/(root)`, then Save.
5. Open the published Pages URL and hard-refresh once if the old version is cached.

The selected work section features NOMO, Mono, Arven, Coinly, and Pink Bear (BEBS). Mono and Arven include prototype links; Coinly and BEBS link to their Figma designs. The site also links to Telegram, Behance, email, and the two supplied App Store pages.
